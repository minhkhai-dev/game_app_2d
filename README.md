🎮 **GAME 2D COLLECTION**

🎯 **Giới thiệu**

Dự án này là bộ sưu tập 5 game 2D được phát triển hoàn chỉnh sử dụng Next.js 14 và TypeScript. Mỗi game đều có đồ họa đẹp mắt, gameplay mượt mà và trải nghiệm người dùng tốt.


✨ **Mục tiêu dự án**

Xây dựng các game 2D hoàn chỉnh, có thể chơi ngay trên trình duyệt

Áp dụng các kỹ thuật lập trình game: game loop, xử lý va chạm, vật lý, AI

Sử dụng TypeScript để đảm bảo type safety và dễ bảo trì

Tạo giao diện responsive, thân thiện với người dùng
